# Vellora-APK
Vellora – aplikasi belanja online Android. Unduh APK terbaru di tab Releases.
## 🛍️ Vellora v0.0.1 – Rilis Perdana

Vellora adalah aplikasi belanja online berbasis Android yang dibangun dengan Ionic, Angular, dan Capacitor. Ini adalah versi pertama yang bisa langsung kamu coba lewat file APK di bawah.

### ✨ Fitur
- 🔐 Daftar & masuk dengan email (verifikasi OTP) atau akun Google
- 🔑 Lupa & reset password
- 🏠 Beranda, katalog, kategori, dan pencarian produk
- 🛒 Keranjang belanja dan voucher
- 💳 Checkout dengan beragam metode pembayaran, termasuk QRIS
- 📦 Riwayat pesanan, rincian pesanan, dan pelacakan pesanan
- 💬 Chat langsung dengan penjual
- 🔔 Notifikasi push
- 👤 Pengaturan profil, alamat, keamanan, dan privasi akun
- 🏪 Fitur seller

### 📲 Cara Install
1. Unduh file **Vellora.apk** dari bagian *Assets* di bawah.
2. Buka file di HP Android kamu.
3. Jika diminta, aktifkan **Izinkan instalasi dari sumber ini** (Install unknown apps).
4. Ketuk **Install**, lalu buka Vellora.

### ⚙️ Persyaratan
- Android 7.0 (Nougat) ke atas
- Koneksi internet

### ⚠️ Catatan
- Ini versi awal (v0.0.1), mungkin masih ada bug.
- APK ini di luar Play Store, jadi Android bisa menampilkan peringatan keamanan saat instalasi. Itu normal.
- Temukan bug atau punya saran? Buka tab **Issues** di repository ini.
